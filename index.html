备份与导出

JSON 用于恢复；Markdown 是人能读的日记本；CSV 可用表格软件打开。AI key 不会出现在任何备份里。

恢复时不会删掉备份里没有的内容，并且会自动留一份恢复前的急救快照，误操作也能救回来。

每月自动备份

每月第一次打开工作台时自动备份一次，内容是你从第一天起的全部数据。电脑上的 Chrome / Edge 可以直接选中 360AI 云盘的同步文件夹，自动写进去：固定一份「小彘的工作台-备份.json」（恢复就读它），同时把带日期的副本自动放进同文件夹下的「小彘的工作台-备份历史」子文件夹，每天一份、永不覆盖旧日期的备份——这就是"备份的备份"，平时不用看。如果当前工作台还没有任何记录，会自动跳过，不会用空数据覆盖云盘里的有效备份。手机浏览器不允许网页写入指定文件夹，会改成一键导出到下载目录，把 360AI 的同步目录设成下载目录即可。

本地密码锁

这是本地弱保护，主要防止别人随手打开看到内容。忘记密码只能清浏览器数据后重新开始。

App 外观（安装到桌面的名称与图标）

隐私说明

你的日记、追踪、份子钱、菜谱等数据默认只存在当前手机浏览器。添加到桌面后仍然是同一份本地数据。换手机前请先导出 JSON 备份。
